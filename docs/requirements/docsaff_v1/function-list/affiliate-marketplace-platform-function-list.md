## MVP1 scope update

MVP1 chỉ thực hiện đến phạm vi: Brand share commission cho Affiliate Platform, sau đó Affiliate Platform cấu hình tỷ lệ/phần chia sẻ commission cho Tenant. MVP1 chưa thực hiện cấu hình cashback B1, tính toán cashback/điểm cho End user, gọi Tenant Loyalty API hoặc cộng điểm cho End user.

Landing page chỉ hiển thị thông tin earn display để khách hàng biết dạng: `Nhận/hoàn x với mỗi y chi tiêu`. Đây là thông tin hiển thị theo từng Tenant + Brand/Offer, chưa phải cam kết hệ thống sẽ tự động tính/cộng cashback/điểm cho End user trong MVP1.

Landing page mặc định hiển thị tiếng Việt (`vi-VN`) hoặc hiển thị theo ngôn ngữ End user lựa chọn. MVP1 hỗ trợ tiếng Việt và tiếng Anh (`vi-VN`, `en-US`). Vì vậy các nội dung cấu hình để hiển thị trên landing page như Brand display content, Offer, Category và Top brand label/section content phải hỗ trợ nhập đa ngôn ngữ trong CMS. CMS cần có cơ chế chọn ngôn ngữ/tab ngôn ngữ để nhập nội dung phù hợp theo từng locale. Banner Management và banner slider được chuyển sang Deferred/Phase 2.

Domain, branding và locale của Tenant không đưa vào nhóm tính năng cấu hình CMS trong MVP1. Dev team/Ops sẽ xử lý các đầu việc này khi setup Tenant mới, gồm domain/routing, DNS/SSL, logo/theme/style token, default locale `vi-VN`, supported locales `vi-VN`/`en-US` và fallback locale.
